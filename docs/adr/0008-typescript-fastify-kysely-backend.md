# TypeScript backend with Fastify, Kysely, and Better Auth

Triathlon v2 remains in TypeScript and runs on Node.js, using Fastify for the HTTP adapter, Kysely with `better-sqlite3` for explicit typed SQL and migrations, and standalone Better Auth against the same SQLite database. Ordered migration files are the schema source of truth and generate checked-in database types. Kysely remains internal to the domain modules rather than being wrapped in repository-per-table interfaces; module and HTTP tests use isolated real SQLite databases. This keeps the backend small enough for the Raspberry Pi target, preserves the team's existing language, supports schema-driven OpenAPI, and leaves a credible path from SQLite to PostgreSQL without adopting a large ORM or another managed service.
