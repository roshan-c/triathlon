# Self-hosted single-node backend with SQLite

Triathlon v2 replaces Convex with a self-hosted modular monolith whose primary target is a 64-bit Raspberry Pi 4B serving at most seven concurrent people or automations. SQLite in WAL mode is the sole durable dependency for v2, with no uploaded-file store, cache, queue, worker, or telemetry service. The independently distributed backend runs as one application process and ships as versioned Linux ARM64/AMD64 container images plus a direct Node.js release. It targets ten thousand tickets and five hundred thousand Activity records with normal indexed operations completing within 500 ms at p95; large histories and Closed tickets are paginated. It provides validated file-and-environment configuration, secure one-time local owner bootstrap, health checks, redacted structured logs, local rate limiting, in-process maintenance, online backup and restore, pre-migration backups, and locked forward-only startup migrations that reject newer database schemas. TLS belongs to a trusted reverse proxy. We accept the single-node limit and will consider PostgreSQL only when observed load or deployment needs make SQLite fail in practice.
