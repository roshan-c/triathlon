# Engineering skills live in a personal fork, synced by a Pi-driven GitHub Action

The engineering skills come from `mattpocock/skills`, installed per repo via `skills-lock.json`. Triathlon tracker support is personal and will never be contributed upstream. We keep it in a personal fork of `mattpocock/skills`. All Triathlon changes sit between `<!-- TRIATHLON-FORK-BEGIN -->` / `<!-- TRIATHLON-FORK-END -->` markers, or live as whole new files. A GitHub Action in the fork (manual + weekly) runs pi headlessly to reconcile upstream: upstream wins everywhere else, marked regions are preserved verbatim, and if upstream deletes a hook point the run stops and flags it in the PR body — never a silent drop. Every sync ends in a reviewed PR. Consuming repos point `skills-lock.json` at the fork. Unmarked local edits are wiped on sync by design; only marked regions persist across syncs.
