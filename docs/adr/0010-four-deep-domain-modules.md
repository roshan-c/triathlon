# Four deep modules own the backend domain

Triathlon v2 is organized around four deep modules: Identity owns users, bootstrap, invitations, sessions, access keys, Automations, suspension, and audit; Projects owns project lifecycle, ownership, membership, board workflow, columns, and authorization; Work owns tickets, ordering, comments, relationships, revisions, review, Resolve, Reopen, deletion, and Frontier; Planning owns sprints, membership, metrics, and frozen snapshots. Their small interfaces are the seams used by callers and tests. HTTP is an adapter over those interfaces, SQLite and Activity recording are internal implementation details, and no business rule may live only in a route, CLI command, or frontend. The npm-workspace repository contains independently deployable server and web apps plus generated-client and remote-CLI packages. Tests cross module interfaces using isolated real SQLite databases, then cover HTTP contracts, authorization matrices, migrations, SSE reconnection, idempotency, and a small first-party UI flow.
